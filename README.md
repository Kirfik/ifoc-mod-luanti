# Independent Flags of Countries
Independent Flags of Countries (`ifoc`) adds country flags and flag pole to Luanti.
This mod is based on and is a hybrid of:
- Pride Flags by Wuzzy;
- Pride Country Flags by snowyu;
- country flag images from flag-icons.
## Features
- Country flags using ISO 3166-1 alpha-2 country codes;- animated waving flags;- flag poles;- support for selecting and placing different country flags;- compatibility with the flag pole system from Pride Flags.
## Usage
Place a flag pole and a flag pole with a flag in the world.
The lower part is the flag pole. The upper part contains the flag and occupiesthree blocks vertically.
After placing a flag pole with a flag, use the place or punch key whilepointing at the flag pole to select another country flag.
Country flags are identified by their two-letter ISO 3166-1 alpha-2 countrycodes. For example:
- `us` — United States;- `gb` — United Kingdom;- `de` — Germany;- `fr` — France;- `jp` — Japan;- `ru` — Russia.
The exact list of available flags depends on the contents of the `textures`directory.
## Requirements
- Luanti 5.4.0 or later.
Older versions may work, but are not officially supported.
## Installation
1. Download the mod.2. Extract it into the `mods` directory of your Luanti game.3. Rename the extracted directory to `ifoc` if necessary.4. Enable the mod in the world configuration.
